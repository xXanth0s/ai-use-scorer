# Third-party notices

The standalone Codex and Claude Code capture adapters are inspired by and adapt the lifecycle event mapping and additive hook configuration approach in Entire CLI 0.11.5, commit `4b8cdfaf0d15e236835c3b7c85d8803b112574bc`.
